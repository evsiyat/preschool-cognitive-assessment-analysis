# Обработанные данные

Обработанный файл подготовлен с помощью **Power Query**.

В нем данные приведены к единому аналитическому формату и дополнены расчетами и справочной информацией.

| Лист | Что показывает |
| --- | --- |
| **Аналитические данные** | основная нормализованная таблица для анализа |
| **Сферы** | агрегированные результаты по диагностическим сферам |
| **Общие баллы** | общий результат ребенка, уровень и % от максимума |
| **Субтесты** | справочник субтестов и их классификация |
| **Младшая** | исходные результаты младшей возрастной группы |
| **Средняя** | исходные результаты средней возрастной группы |
| **Старшая** | исходные результаты старшей возрастной группы |
| **Подготовительная** | исходные результаты подготовительной возрастной группы |
