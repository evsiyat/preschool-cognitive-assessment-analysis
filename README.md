## Анализ результатов экспресс-диагностики умственной сферы детей дошкольного возраста

### О проекте

Проект посвящен анализу результатов экспресс-диагностики умственной сферы **307 детей дошкольного возраста** из четырех возрастных групп: младшей, средней, старшей и подготовительной.

Цель проекта - структурировать результаты диагностики, выявить особенности распределения показателей по возрастным группам и диагностическим сферам, а также представить результаты в интерактивном дашборде.

Проект выполнен на основе результатов диагностики по методике **Павловой Н.Н. и Руденко Л.Г.**

### Что было сделано

* Собрала и структурировала данные о результатах диагностики 307 детей из четырех возрастных групп.
* Провела предобработку и контроль качества данных.
* Привела данные к единому аналитическому формату с помощью **Power Query**: объединила результаты возрастных групп, преобразовала данные из широкого формата в длинный и связала их со справочником диагностических субтестов.
* Сформировала показатели для сопоставления возрастных групп с учетом различий в количестве и составе субтестов.
* Разработала интерактивный дашборд в **Yandex DataLens** для анализа общей картины, сравнения возрастных групп, распределения детей по уровням и детализации результатов по субтестам.
* Проанализировала результаты и сформулировала аналитические выводы и рекомендации.

### Основные результаты

В общей структуре результатов:

* **66.1%** детей имеют средний уровень;
* **28.0%** - высокий;
* **5.9%** - низкий.

Средний показатель выполнения по всей выборке составил **65.9%**.

По диагностическим сферам наиболее высокие средние показатели отмечаются по:

* памяти - **75.24%**;
* общей осведомленности - **74.54%**;
* мышлению - **74.51%**.

Наиболее низкие средние показатели отмечаются по:

* воображению - **39.16%**;
* мелкой моторике - **41.71%**;
* мышлению и речи - **57.22%**.

При детализации по отдельным субтестам выявлены существенные различия в распределении результатов внутри одних и тех же диагностических сфер. Это позволяет переходить от общей оценки сферы к анализу конкретных заданий.

Подробные результаты и интерпретация представлены в [аналитической справке](analysis/analytical_note.md).

### Дашборд

Интерактивный дашборд разработан в **Yandex DataLens**.

**[Открыть интерактивный дашборд →](https://datalens.yandex/ccskcwleqyf2v?_share_link=public)**

Дашборд позволяет:

* оценить общую структуру результатов;
* сравнить возрастные группы;
* проанализировать результаты по диагностическим сферам;
* изучить распределение баллов по отдельным субтестам;
* перейти от общей картины к более детальным результатам.

### Инструменты

* **Excel** - исходные данные и расчеты;
* **Power Query** - очистка, преобразование и объединение данных;
* **Yandex DataLens** - визуализация и интерактивный дашборд;
* **Markdown / GitHub** - оформление и публикация проекта.

### Данные

`data/raw/` — исходный Excel-файл с результатами диагностики.

`data/processed/` - обработанный Excel-файл с подготовленными аналитическими таблицами.

В обработанном файле представлены:

* нормализованные данные по отдельным субтестам;
* результаты по диагностическим сферам;
* общие результаты и уровни;
* справочник субтестов и диагностических сфер.
